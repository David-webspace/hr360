# 職工福利辦法

本辦法由職工福利委員會執行，福利金不屬工資，不列入薪資單。

### 第1條 三節禮金
春節 3,000 元、端午節 2,000 元、中秋節 2,000 元，於節日前一至兩週發放；發放日在職者始得領取。

### 第2條 生日禮券
員工生日當月發放 1,000 元禮券。

### 第3條 婚喪喜慶
1. 結婚禮金：6,000 元，夫妻同為本公司員工者各自請領。
2. 生育補助：每名新生兒 6,000 元。
3. 喪葬補助：員工本人 30,000 元；父母、配偶、子女 8,000 元；配偶之父母 5,000 元。
上述補助應於事實發生後三個月內檢附證明文件申請。

### 第4條 住院慰問
員工連續住院 3 日以上者，每次致贈慰問金 3,000 元，每年以 2 次為限。

### 第5條 健康檢查
未滿四十歲者每 2 年、四十歲以上者每年一次，補助健康檢查費用，每次上限 5,000 元，於特約醫院檢查或檢據核銷。

### 第6條 社團補助
經福委會核准成立之社團，每名參加員工每月補助 300 元活動經費。

### 第7條 員工旅遊
依員工旅遊補助辦法辦理。
