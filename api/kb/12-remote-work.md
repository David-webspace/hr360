# 遠距工作辦法

### 第1條 適用對象
研發中心、營運中心之員工，試用期滿、最近一次考核 B 以上者，得申請遠距工作。製造中心現場人員、業務中心因職務性質原則不適用，經中心主管核准者不在此限。

### 第2條 天數上限
遠距工作每週最多 2 日，不得連續兩週全數集中於同一週間日。

### 第3條 申請方式
應於遠距工作日前 1 日於 HR 系統提出，經直屬主管核准。

### 第4條 工時認定
遠距工作日之工作時間依工作規則辦理，以公司 VPN 登入系統之打卡紀錄為出勤紀錄。遠距期間之延長工時，仍應事前申請加班。

### 第5條 資訊安全
遠距工作應使用公司配發之電腦並全程連線 VPN，不得於公共場所處理機密資料，不得使用個人雲端儲存公司文件。

### 第6條 職業災害
遠距工作期間於約定工作場所執行職務所致之傷害，依職業災害相關規定認定。
