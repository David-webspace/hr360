## 本專案的解讀選擇（非法條明文，需在 README 揭露）

- 曆年制特休：依服務年度落在各曆年的日數比例分配；滿 6 個月的 3 日於取得當年一次給足；以小時計、未滿 1 小時進位。
- 2/29 到職者，平年的週年日以 2/28 計。
- 年資計算 `end - start` 不含終止日當天。
- 金額：應給付者（加班費、資遣費）無條件進位到元；應扣款者（請假扣薪）無條件捨去。
- 民間企業國定假日逢週末的補休日由勞資協商；曜川科技採人事行政總處補假日。
